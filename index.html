Por que o Firefox bloqueia e como resolver?

O YouTube e o Firefox possuem uma política de segurança estrita (X-Frame-Options): quando uma página é aberta diretamente como arquivo (endereço file:///...), o YouTube bloqueia a exibição dentro de iframes para evitar ataques de clique.

✅ Solução 1 (Recomendada): Usar o Iniciar.bat (1 Clique)

Criamos um inicializador automático para você!

  1. Abra a pasta onde está o MultiChat.
  2. Dê dois cliques no arquivo Iniciar.bat.
  3. Ele abrirá o MultiChat em http://localhost:3000 no seu navegador com 100% dos chats do YouTube e Twitch liberados diretamente na tela!
🗗 Solução 2: Abrir em Janela Popout (Sem Servidor)

Se preferir não usar o Iniciar.bat, basta clicar no botão Popout (↗) no topo do chat do YouTube. O chat abrirá em uma janela popup limpa e compacta, sem nenhum bloqueio do navegador!

Sobre o MultiChat Live Pro

MultiChat Live Pro 2.1 é uma central tudo-em-um para acompanhar múltiplos chats de streaming simultâneos em tempo real (Twitch, YouTube, Kick, Trovo e links personalizados).

🚀 Dicas e Recursos:

  • Popout Independente: Clique no botão ↗ no topo de qualquer chat para abrir uma janela compacta sem bordas, excelente para monitores secundários.
  • Zoom para Leitura: Use os botões − e + em cada chat para aumentar as fontes e ler com facilidade mesmo de longe.
  • Modo OBS Studio: Pressione F2 ou clique no botão OBS no topo para ativar fundo transparente e usar direto como Fonte de Navegador (Browser Source).
  • Renomear Chat: Dê duplo-clique no título de qualquer chat e digite direto ali. Enter salva, Esc cancela.
  • Organização: Arraste qualquer chat pelo cabeçalho para trocar de lugar, use as setas ← →, ou fixe no início com 📌.
  • Colar e pronto: Com um link de live copiado, aperte Ctrl + V em qualquer lugar da página para adicionar o chat.
  • Cronômetro: Continua contando mesmo se você fechar ou recarregar a página.

💬 Mandar mensagens pelo MultiChat:

Dá sim! Clique no botão ⇥ Entrar no topo do chat, faça login na Twitch, YouTube, Kick ou Trovo na janelinha que abrir e feche ela. O chat recarrega já logado e você pode digitar e comentar direto dali.

Se continuar pedindo login, o navegador está bloqueando cookies de terceiros (o Chrome, o Brave e o Firefox no modo estrito fazem isso). Libere cookies para localhost nas configurações do site (ícone ao lado do endereço), ou use o ↗ Popout: na janela de popout o login sempre funciona.

💡 Solução de Problemas com a Twitch:

A Twitch exige que o parâmetro parent corresponda exatamente ao domínio em que o chat está incorporado. Caso você abra o arquivo diretamente pelo Explorer (file://) e veja uma mensagem de erro da Twitch, use o botão de Popout (↗) ou execute via servidor local (ex: extensão Live Server do VS Code ou localhost).
